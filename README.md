# k2db

Kraken 2 database management tool

## Quick Start

```
% k2db -v
0.1.0

```

## Installation

### Conda
If you are using [Conda](https://bioconda.github.io/user/install.html)
```
% conda install -c bioconda k2db # COMING SOON
$ k2db -h
```
